
# ỨNG DỤNG QUẢN LÝ CÔNG VIỆC CÁ NHÂN
## Personal Task Manager

### 1. Giới thiệu
Personal Task Manager là ứng dụng quản lý công việc cá nhân được xây dựng bằng Flutter và Dart trong khuôn khổ học phần Lập trình thiết bị di động.

Ứng dụng hỗ trợ người dùng tạo, chỉnh sửa, xóa và theo dõi tiến độ công việc.

### 2. Thông tin thực hiện
- Họ và tên: Nguyễn Đức Toàn
- Mã sinh viên: 24100230
- Hình thức: Cá nhân 
- Học phần: Lập trình thiết bị di động

### 3. Mục tiêu
- Hỗ trợ quản lý công việc cá nhân.
- Theo dõi trạng thái hoàn thành.
- Sắp xếp công việc theo mức độ ưu tiên.
- Thống kê tiến độ thực hiện.

### 4. Chức năng
- Thêm công việc mới.
- Chỉnh sửa thông tin công việc.
- Xóa công việc.
- Đánh dấu hoàn thành.
- Tìm kiếm công việc.
- Lọc công việc theo trạng thái.
- Thống kê tiến độ công việc.

### 5. Công nghệ sử dụng
- Ngôn ngữ: Dart.
- Framework: Flutter.
- Công cụ phát triển: Android Studio.
- Quản lý mã nguồn: Git và GitHub.

### 6. Cài đặt và chạy ứng dụng

Yêu cầu đã cài đặt Flutter SDK và Android Studio.

Các lệnh thực hiện:

```bash
git clone https://github.com/24100230-lab/24100230_TaskManager.git
cd 24100230_TaskManager
flutter pub get
flutter run
```

### 7. Quản lý dữ liệu
Phiên bản hiện tại sử dụng dữ liệu lưu tạm trong bộ nhớ ứng dụng để kiểm thử các chức năng.

### 8. Tiến độ phát triển
Dự án tiếp tục được hoàn thiện theo yêu cầu của học phần Lập trình thiết bị di động.
